# Triagem inicial

1. Recupere os sintomas, o início e os dados relevantes já informados. Trate idade, gestação, comorbidades, sangramento e piora como desconhecidos quando o relato estiver em silêncio.
2. Use `resumir_checklist_triagem` para organizar esses dados. Preserve os detalhes e a cronologia no histórico. Se a pessoa perguntar pela origem dos manuais, consulte `listar_fontes_oficiais`.
3. Busque com `search_protocolos` os critérios oficiais que se aplicam ao relato e a conduta correspondente. Inclua na consulta os achados relevantes, o que falta esclarecer e se há necessidade de investigar urgência.
4. Dê prioridade à orientação de urgência quando sustentada pelo protocolo. Para os demais casos, use a fonte localizada para orientar o próximo passo e identificar a pergunta pendente que mais pode mudar a conduta. Trate a classificação como provisória enquanto faltarem dados essenciais.
